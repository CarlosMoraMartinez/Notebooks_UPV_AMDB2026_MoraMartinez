# Curso de Bioinformatica con Python

Repositorio base para organizar notebooks, materiales y codigo auxiliar del curso.

## Estructura

- `notebooks/`: notebooks del curso organizadas por bloques.
- `data/raw/`: datos originales.
- `data/processed/`: datos transformados para ejemplos o practicas.
- `src/`: utilidades y funciones auxiliares en Python.
- `docs/`: documentos de apoyo y guias breves.
