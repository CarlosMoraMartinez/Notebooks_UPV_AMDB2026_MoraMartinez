# Ejercicios prácticos para la asignatura Análisis masivo de datos biológicos (13682)

Este repositorio contiene todos los ejercicios prácticos preparados para la asignatura Análisis masivo de datos biológicos (13682), impartida en 3er curso del Grado en Biotecnología de la Universidad Politécnica de Valencia, durante el curso 2026. 

**Nota: El repositorio no se corresponde con prácticas impartidas de facto durante el presente curso, sino que se ha desarrollado en el contexto del concurso público con código 7948 para optar a una plaza de Ayudante Doctor.**

## Estructura

- `notebooks/`: notebooks del curso organizadas por bloques.
- `data/raw/`: datos originales.
- `data/processed/`: datos transformados para ejemplos o practicas.
- `src/`: utilidades y funciones auxiliares en Python.
- `docs/`: documentos de apoyo y guias breves.
