# Estructura inicial del repositorio

Este repositorio se ha creado para almacenar notebooks de Python orientados a un curso de bioinformatica.

## Organizacion propuesta

- `notebooks/02_Python_Fundamentos/`: contenidos introductorios de Python.
- `data/raw/`: ficheros de entrada sin modificar.
- `data/processed/`: resultados intermedios o datos preparados.
- `src/`: funciones reutilizables.
- `docs/`: documentacion del curso.

## Notebook inicial

La notebook `2.1_VariablesYTipos.ipynb` introduce:

- variables
- tipos basicos
- conversiones
- ejemplos sencillos con contexto bioinformatico
